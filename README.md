# Notiva

Lokale Notion-Alternative für macOS. Keine Kollaboration, kein Cloud-Zwang. Gebaut mit Rust und Tauri, Daten in SurrealDB (embedded).

Das Projekt steht am Anfang. Was gebaut wird und in welcher Reihenfolge, steht in der [Capability Map](docs/specs/CAPABILITY-MAP.md). Der Backlog lebt in den [Issues](https://github.com/novexlab/notiva/issues).
